# Support

Use GitHub Issues for reproducible bugs and scoped feature requests. Use GitHub
Discussions for usage and design discussion when enabled. Report vulnerabilities
privately as described in [SECURITY.md](SECURITY.md).

Bug reports should include the OS and architecture, tool versions, ImperaOS commit or
release, exact command, a minimal reproduction, and redacted logs. Never upload
secrets, customer data, production prompts, or unredacted evidence bundles.

Preview, pilot, qualification-gated, and other constrained surfaces are not general
availability commitments.
