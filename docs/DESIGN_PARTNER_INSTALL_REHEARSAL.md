# Design Partner Install Rehearsal

Use this rehearsal before the first design partner install:

1. Pull the release branch.
2. Run `make design-partner-rc-gate`.
3. Review `artifacts/design-partner-rc/DESIGN_PARTNER_RC_REPORT.md`.
4. Confirm computer-use live and public desktop installer claims remain blocked.
5. Register only approved external agents.
6. Validate policy pack changes with promotion dry-run before activation.
