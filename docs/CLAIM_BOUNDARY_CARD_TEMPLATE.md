# Claim Boundary Card Template

Use this card in every design partner RC handoff.

## Supported

- Self-hosted local Agent Control Plane.
- Hash-only redacted evidence.
- Deterministic governed pilot workflow.
- Operator-reviewed handoff pack.

## Not Claimed

- Public desktop installer readiness.
- Live macOS, Windows, or Linux computer-use.
- Multi-tenant cloud control plane.
- Approval-free irreversible mutation.
- Live external provider execution by default.

## Stop Conditions

- Any no-ship claim is allowed.
- Any raw prompt, response, screenshot, secret, or PII marker is present.
- Strict RC promotion is blocked.
- Independent operator attestation is missing or invalid.
- Handoff verification is blocked.
