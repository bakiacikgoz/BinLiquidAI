# Operator Workspace IA

## Shell

- Left rail: conversations, tasks, saved sessions, primary navigation
- Center: chat transcript, streamed state, composer, attachments
- Right rail: live timeline, approvals, run context, artifacts, diagnostics

## Primary Workspaces

### Workspace

- chat transcript
- streamed response / state badges
- message composer
- attached files and run context chips
- recent sessions
- operator controls
- live action timeline
- approvals and artifacts stack

### Tasks

- request entry
- profile selection
- spec path input
- advanced options for provider/model overrides
- submit and resume entry points

### Approvals

- pending queue
- selected approval detail
- explicit approve / reject / execute controls

### Runs

- run list
- overview
- stream / timeline
- approvals
- artifacts
- replay
- diagnostics

### System

- doctor
- config resolve
- capabilities
- effective profile/config

### Operations

- identity
- qualification
- security
- keys
- support
- backup / restore / migrate

### Settings

- runtime resolution paths
- locale / theme
- debug raw opt-in
- telemetry opt-in

## Layout Principle

- The chat workspace is the primary entry surface.
- Structured views such as Tasks, Approvals, Runs, and System remain available for deep inspection and recovery.
- Operator controls stay close to the live timeline so interrupt, approval, and replay actions do not require context switching.
